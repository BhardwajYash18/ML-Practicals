# Machine Learning Practicals

This repository contains the practical implementations performed as part of the Machine Learning Laboratory.

## Practicals

### Lab 1 — Data Preprocessing

**Aim:**  
To study and apply Data Preprocessing techniques on a given dataset and prepare the Titanic dataset for training with a machine learning algorithm.

**Dataset:**  
Titanic Dataset

**Preprocessing Techniques:**
- Data inspection and understanding
- Handling missing values
- Categorical data encoding
- Duplicate data checking
- Outlier detection and removal
- Data visualization
- Feature scaling
- Feature and target separation
- Train-test split

**Files:**
- [Lab 1 Notebook](Lab-1_Data-Preprocessing/YashBhardwaj_ML-1.ipynb)
- [Titanic Dataset](Lab-1_Data-Preprocessing/titanic.csv)
